# Clinical Data Standards Skills

Reusable agent skills for clinical data standards and Medidata Rave study build work.

## CDASH + CDISC Mapping

The skill is stored at:

`skills/cdash-cdisc-mapping/`

It helps map CRF questions and Rave metadata to CDASH and SDTM structures, while distinguishing standard variables from sponsor-defined Field OIDs.

### Installation

Install or copy the `skills/cdash-cdisc-mapping` directory into a supported agent skills directory, preserving `SKILL.md` and the `references/` folder.

For project-scoped Codex use, copy it to:

`.codex/skills/cdash-cdisc-mapping/`

Review all mappings against the sponsor's approved standards library, protocol, imaging charter, and the CDISC versions selected for the study.
